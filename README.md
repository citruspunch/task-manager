# Task Manager

## Description
This is a simple task manager that allows you to add, delete, and view tasks. It is built using React and React-bootstrap.

## Setup Instructions

1. Clone the Repository:
    ```bash
    git clone https://github.com/citruspunch/task-manager.git
    ```
2. Navigate to the project directory:
    ```bash
    cd task-manager
    ```
3. Install the dependencies:
    ```bash
    npm install
    ```
4. Start the development server:
    ```bash
    npm run dev
    ```
5. Open your browser and go to `http://localhost:5173` to view the application.

## Usage Examples
- Add a new task by entering the task name and clicking the "Add Task" button.
- View the list of tasks displayed on the screen.
- Delete a task by clicking the "Delete" button next to the task you want to remove.
- Edit a task by clicking the label from the task you want to edit.
- The task list will update automatically to reflect the changes.
- The task manager is responsive and works well on both desktop and mobile devices.
- The application is styled using React-bootstrap for a clean and modern look.
